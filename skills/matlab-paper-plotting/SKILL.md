# MATLAB 论文绘图

先明确数据含义，再选择能支持结论的图型。将数据读取、数值计算和样式设置分开；不在美化时改变模型、统计口径或真实数据。

## 工作方式

确认轴和单位、系列身份、比较目的、区间定义、最终版面宽度及用户指定的风格。只有演示请求可以使用明确标记的合成数据；缺真实数据时不静默回退为合成数据。

按需求使用 [图型与误差表达](references/plot-recipes.md)。连续趋势用曲线，观测/拟合用点线，离散估计用误差棒，连续范围用色带；类别不强行连线，双参数响应才考虑曲面。

在项目中写绘图入口并调用所需辅助函数；交付时包含这些函数，使工程无需依赖已安装技能的位置。技能文件不作为数据输出目录。使用现有 MATLAB 实际运行；缺环境时明确报告未运行，不以其他工具生成的图冒称 MATLAB 结果。

## 样式和真实性

- 沿用模板要求。无指定时以白底、浅主网格、颜色与线型双重编码、少量强调色为起点；同一系列跨图保持身份。
- 按实际插入宽度设置字号，不靠扩大画布后整体缩小解决拥挤。中文、数学标签分别选择本机可用字体/解释器，不更改全局字体默认值。
- 图例显式使用主要对象句柄，避免辅助线和色带重复入图例。区间先画，主线后画。
- SD、SE、置信区间、预测区间和参数范围各有不同含义；只使用输入支持的名称。不要把 ±1σ 自动改称95%置信区间。
- 缺测保持缺口；不为好看平滑、裁掉异常、删改数据或缩窄误差范围。若作额外数据变换，先说明其定义、依据及对结论的影响。
- 阈值和最优点须有计算或用户依据，网格最小值不冒称连续全局最优。

## 辅助函数

这5个 `.m` 文件只用基础 MATLAB 绘图功能；需要支持 `exportgraphics`、`tiledlayout` 等函数的版本，旧环境先检查能力，不直接安装或升级。

| 文件 | 作用 |
|---|---|
| `scripts/paper_palette.m` | 通用五色色板 |
| `scripts/paper_axes.m` | 局部坐标轴风格和可用字体选择，不改全局默认值 |
| `scripts/paper_band.m` | 给定上下界的分段色带，保留NaN缺口，拒绝非法顺序/上下界 |
| `scripts/paper_export.m` | 保存FIG、300 dpi PNG与PDF；先选择不会覆盖独立成果的输出stem |
| `scripts/demo_gallery.m` | 六类图型的合成示例，图中明确标记，不可当成比赛结果 |

示例在 MATLAB 中运行：
```matlab
addpath(fullfile(skillDir,'scripts')); % skillDir为实际技能目录
demo_gallery(fullfile(projectDir,'demo_figures')); % 只生成合成演示
```

## 交付检查

交付绘图入口、必要函数、数据来源说明及实际生成的FIG/PDF/PNG。按最终尺寸检查单位、中文、上下标、图例、裁边、区间层级和缺测处。密集矢量图过大时可以说明后采用栅格导出，不以静默降采样替代完整数据。报告实际运行与视觉检查状态，字体缺失等限制要具体。
