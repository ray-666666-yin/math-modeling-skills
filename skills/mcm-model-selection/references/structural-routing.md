# 从问题结构缩小候选

以下是通用方法的抽象示例，不是按题目字母或行业名称匹配的答案库。只读取相关分支；所列方法也不是穷尽清单。

| 已确认的结构 | 可先考虑的基线 | 决定是否升级的证据 |
|---|---|---|
| 连续可分资源，目标与约束均为线性 | 线性规划 | 出现真实整数决策、非线性机制或信息分阶段到达 |
| 资源数量、开关或分配不可连续取值 | 整数/混合整数模型；很小时可枚举 | 可行域规模、可用求解时间与可证明的解质量 |
| 有明确收支、状态演化及初边值 | 相应的代数、常微分或偏微分模型 | 简化的空间/时间尺度是否足以解释所求输出 |
| 由观测反推少量未知参数 | 明确观测关系的估计或反演 | 参数是否可辨识；噪声、约束与残差结构是否被表达 |
| 面向未见样本预测 | 简单可解释预测基线 | 独立验证表现是否支持更复杂模型；是否存在泄漏 |
| 同一对象有重复测量或层级结构 | 能表示对象差异的统计模型 | 是否需要解释组间/组内差异；新对象和已知对象的目标是否不同 |
| 时间、几何和接触共同决定事件 | 几何关系加事件判据 | 离散采样是否可能漏事件；判据与搜索所需性质是否成立 |
| 当前决策后才获得不确定信息 | 情景或多阶段决策模型 | 哪些决策可以在观测后调整，哪些必须提前共享 |

## 例一：整数决策不能靠最后取整补上

合成任务：分配若干不可拆分设备，选择数量为整数 $x_i$，资源约束为 $Ax\le b$，目标为 $c^\mathsf T x$。这时整数要求属于模型本身。连续松弛可以给界或辅助求解，但输出取整后需重新检查可行性和目标值；不能把连续最优直接称为设备分配方案。

若资源本来允许任意分割，则不应仅因“分配”一词强行加入整数约束。

## 例二：观测关系决定能估什么

合成观测式：$y_i=abx_i+\varepsilon_i$，且没有分别约束 $a,b$ 的其他信息。现有关系只体现其乘积；更复杂的优化器不会自动增加可辨识信息。可考虑估计组合参数、引入有依据的外部标定，或报告无法分别估计的局限。

## 例三：验证对象必须对应使用对象

合成数据：每台设备有多条连续观测。若任务是预测从未出现的新设备，随机打散记录可能让同一设备同时进入训练与验证。选型比较应按设备划分，并确保预处理只从训练部分学习。若任务是已知设备未来时段的预测，则还需按时间顺序构造评估。

## 例四：搜索方法不能替代事件定义

合成任务：移动实体首次接触边界。先定义实体几何和接触判据，再决定事件定位方式。固定时间网格上未发现接触不等于连续时间绝无接触；布尔二分也需要相应的单调结构，不能因时间只有一维就直接采用。

这些例子帮助明确前提，不提供通用的样本量、步长或误差阈值。阈值应来自本题输出要求、数据分辨率和数值误差评估。
