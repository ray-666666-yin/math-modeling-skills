# 视觉与逻辑检查

无指定风格时可用白底、深灰字、低饱和填色：输入绿色、模型蓝色、计算浅黄、判断浅粉、结果浅橙。角色色不代替文字或“是/否”分支标注，复现模式以参考为准。

先固定阅读方向与实际论文宽度，再选字号和框体大小。同层节点尽量等宽、等高、等距；长标签分行或拆为标题和说明。反馈走外侧留白，线不穿文字；分组框表示范围而非未定义运算。

- 总路线：跨阶段箭头连真实交接物，不从每个框向后面所有框发箭头。
- 并行耦合：分支输入/输出明确，汇合不改变数学依赖。
- 条件选择：菱形写判据，出口写条件；不能把必要条件画成充分条件。
- 迭代反馈：返回目标、调整变量和停止条件都来自实际算法；缺失时标明待补。
- 公式：上下标、单位、粗体向量等沿用当前稿件；不要用图片美化掩盖含义冲突。

最终检查节点边界、标签高度、线与文字距离、箭头端点、字体替换及论文缩放后可读性。XML坐标有效、对象可编辑与最终渲染清楚是三个独立检查。
