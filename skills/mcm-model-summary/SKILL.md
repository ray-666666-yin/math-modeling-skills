# 已有模型的公式汇总

把分散在正文中的模型关系整理成可读的小结，保持来源和数学含义可核对。只请求片段时交付片段；请求插入正文时在指定位置新增，保留原推导和已有内容。

## 先确定汇总范围

阅读目标问题的方程、符号定义、假设和相关初边值或约束。检查目标模板的数学环境、字体和标签习惯。没有完整项目时可以交付适配说明，不必为一个片段另建整套论文。

为每一条拟摘录关系找到原公式标签、段落或可定位的源位置；参数说明同样需要来源。源材料是 Word 时核对原生公式结构或清楚的渲染，不能从普通文本拼接猜测分母、上下标和根号范围。

## 提取而不补造

按依赖关系选择输入关系、核心方程、必要条件和输出关系。删去重复推导可以，但不能省掉使关系成立的范围、边界或约束。

保留等号与近似号、变量名称、上下标、向量区别、索引范围、单位和已有数值。缺少定义或源文自相矛盾时，列出具体位置和缺项；不要从其他论文、旧案例或常识中悄悄补成完整模型。可先完成无争议部分，并说明汇总的覆盖范围。

汇总不会增加验证强度。源文只是模型假设或经验关系时，不能通过标题和大括号把它升级成定理、已证明性质或已验证结论。

## 组织 LaTeX 片段

通常使用一个有标签的公式组，左侧大括号、逐行关系、右侧简短用途；按内容选择 `cases` 或 `aligned`。需要参考结构时读 [合成排版示例](references/latex-example.md)，不要把示例中的模型搬进用户正文。

- 沿用现有数学字体与宏包，不为小结更换整套模板。
- 算子、说明文本和单位使用适当的数学命令；字形统一不能抹去原稿用粗体或不同符号表达的区别。
- 按现有标签约定生成唯一新标签，使用自动交叉引用，不手写最终编号。原公式标签保持不变。
- 在源码注释中标记摘录来源，避免把内部文件位置写进论文正文。
- 长行优先合理断行；过高的括号组按实际子模型拆分。不要依赖整体缩小字号掩盖溢出，也不要为缩短公式新造未定义变量。

允许不改变数学含义的排版调整；不为一般字距或换行重复请求确认。若存在实质性的源文冲突，先完成可确定内容，再提出需要解决的具体问题。

## 解释符号

在公式组后用短段或表格说明实际出现的输入、待求量、参数、索引和适用条件。角色分类依本题而定，不把所有符号都称为常数。

每个符号有可追溯含义；原文未给单位、数值或外部函数表达式时如实说明。已有定义可引用，参数多时再用表格，避免重复堆砌正文。

## 核对与交付

逐行对照源式与适用条件，核对符号说明、唯一标签和引用对象。具备项目与编译工具时，沿用现有环境编译并检查受影响页面：括号、右侧说明、长公式和相邻参数段落应完整可读。仅交付片段或环境不可用时，明确未执行的验证。

交付用户要求的源码或片段，附简短的来源、内容新增和未决项说明；需要 PDF 时同时提供实际生成的文件。区分内容比对、编译与数学正确性，不把排版成功说成模型验证完成。本技能独立可用，无必装的其他技能。
